# Java-Learning-Journey
A beginner-friendly collection of Java programs covering fundamental concepts and programming basics.

This repository contains Java basic programs that I wrote while learning Java. It is designed to build a strong foundation in Java programming.

- User Input

- Basic Pattern Programs
- Basic Number Programs

## 🛠️ Language

To learn Java fundamentals and improve programming skills through regular practice.
